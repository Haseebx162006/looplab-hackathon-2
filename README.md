# looplab-hackathon-2

Fullstack AI Workspace with Next.js 15, Express.js (JavaScript), PostgreSQL, and Native pgvector + Hybrid RAG Pipeline.

## Features
- **Frontend**: Next.js 15, TypeScript, Tailwind CSS, Feature-Sliced Design.
- **Backend**: Express.js (JavaScript), PostgreSQL, pgvector embedding similarity search, tsvector full-text search, Reciprocal Rank Fusion (RRF).
- **RAG Pipeline**: Ingest custom knowledge documents, vector chunking, hybrid retrieval, grounded QA answering with confidence scoring.

## Getting Started

### 1. Backend Setup
```bash
cd backend
npm install
npm run dev
```

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
